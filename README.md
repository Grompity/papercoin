# $PAPER — paper website

a premium single-page site for the **$PAPER** solana memecoin, plus
**PAPERBOARD** — post PAPER, earn points, climb the front page.

vanilla html/css/js up front — no build step, es modules, one brand
stylesheet + one paperboard stylesheet. the board's brain is a small
stdlib-only python server (no third-party deps).

## run it

the board server serves the site AND the api from one port — run this:

```sh
.venv/bin/python3 "Paper Website/server/run.py"
# open http://localhost:5199
```

- mock mode is automatic when `X_CLIENT_ID` / `X_API_BEARER` are absent
  (a seeded demo world; the UI stamps every mock number `mock feed`).
- **live mode needs the environment, never a file**: `X_CLIENT_ID`,
  `X_CLIENT_SECRET`, `X_API_BEARER` (plus optional `X_REDIRECT_URI`;
  live mode raises at boot without the bearer — it fails loudly, never
  silently mocks). `PAPER_ADMIN_TOKEN` guards the refresh route; without
  it, live admin calls answer 503 rather than guessing.
- `PAPER_PORT`, `PAPER_DB_PATH`, `PAPER_MOCK`, `PAPER_SCHEDULER` tune it;
  secrets come from the environment only.
- cron mode: `run.py --once` refreshes the standings snapshot and exits.
- static-only fallback (no api): `python3 -m http.server 5199` from this
  folder — the front page prints clearly-labeled DEMO rows.

the server's own battery: `.venv/bin/python3 "Paper Website/server/selftest.py"`
(eligibility, scoring, prizes, tiers, wallet, scan, http, competitions,
hardening — all in-process).

## the board's rules at a glance

- a post is eligible when it carries an identifier (CA / `@paperusdc` / `$PAPER`)
  **and** the author follows `@paperusdc`; a later follow is retroactive on
  the next scan.
- scoring is transparent (`pb-v1`): base per post + per-engagement points,
  a diminishing impressions curve, duplicate + frequency zero-outs, a
  per-window cap — the server's audit trail is rendered, never re-divined.
- prizes are `mixed` (proportional slice + top-3 slice + community slice)
  over a 1,000,000 `$PAPER` pool.
- the front page is a SNAPSHOT, refreshed ~4× a day by the scheduler —
  never sold as real-time.
- the frontend never sends a score upward: only a code, a wallet, and
  its own impatience. the issue line in the hero ("entries open · ends
  Nov 1") is drawn from `/api/competitions` — the server owns the
  calendar; live/upcoming/ended/closed/none all render, an offline
  fallback prints the printed default.

## design notes (the simplify pass)

- the press rules for noise: no ticker strip, no edition strip, one panel
  frame (no dashed double), no per-row tier badges (the legend states the
  tiers once, rank coloring carries them), no mini-board (the full table
  is right there), no out-press rows section (the footer is the socials).
- the one image motif is the PRINTED PLATE: a cream block carrying the
  art with `mix-blend-mode: multiply`, so the art's white ground fuses
  into the paper (a newspaper halftone, not a white card). hero + the
  bill carry it full; the panel states carry it small; captions only
  where the joke lands (hero, bill).
- the hero is one sentence: kicker (server's issue line) → the giant
  sentence → one supporting line → Connect X / Buy / PAPERBOARD. the
  masthead IS the brand line; the mascot is the plate on the right.
- motion is three things only: one scroll reveal, hero pointer parallax,
  and state-feedback pulses (scanline, live dot). all honor
  `prefers-reduced-motion`.
- the leaderboard grid is deliberately five columns — it shows the
  server's five facts and no more.
